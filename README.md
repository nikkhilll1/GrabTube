## ✨ Features

- 🎯 **One-Click Downloads** — Paste a URL and download instantly
- 🎥 **Multiple Formats** — MP4, MP3, WebM, and more
- 📊 **Real-Time Progress** — Track download speed and progress
- 📁 **Custom Output Folder** — Choose where your files go
- 🎨 **Premium Dark UI** — Beautiful, modern glassmorphism design
- ⚡ **Powered by yt-dlp** — Reliable and fast downloads

## 🛠️ Development

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [Git](https://git-scm.com/)

### Setup
```bash
# Clone the repository
git clone https://github.com/nikkhilll1/GrabTube.git
cd GrabTube

# Install dependencies
npm install

# Run in development mode
npm run dev
```

### Build
```bash
# Build Windows installer
npm run dist
```
